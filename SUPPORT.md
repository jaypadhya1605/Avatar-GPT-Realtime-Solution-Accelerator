# Support

This repository is a reference accelerator, not a managed service or clinical product.

- For reproducible accelerator defects, use the GitHub bug report form with synthetic data and sanitized diagnostics.
- For design proposals, use the feature request form.
- For vulnerabilities, use the private process in [SECURITY.md](SECURITY.md).
- For Azure subscription, quota, region, billing, service-health, or Limited Access issues, use [Azure Support](https://azure.microsoft.com/support/options/) or Microsoft Learn product support.

Before reporting a problem, run `./scripts/test.ps1`, check `/healthz` and `/readyz`, and review [Operations](docs/operations.md) and [Custom Photo Avatar](docs/custom-photo-avatar.md). Do not post patient data, credentials, character names, consent media, signed URLs, or private deployment identifiers.
